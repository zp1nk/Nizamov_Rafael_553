# Текстовый квест

В проекте две версии квеста.

## Задание 1 — while
Папка `task1_while` содержит квест, развивающий базовый квест с помощью цикла `while`.

## Задание 2 — def
Папка `task2_def` содержит версию квеста, разбитую на функции.
Для изменения здоровья функции урона и лечения используют `return`.
